# 图片读取和带宽优化

2026-10-19 本地实现与验证记录；本记录不代表已发布到生产。

## 请求链路

- TMDB 符合直连条件的图片继续返回 CDN 302。
- 普通本地原图、已缓存的远程原图：打开并检查原图大小与修改时间，计算原有变体缓存键，优先发送已生成的变体。缓存未命中才读取原图、验证读取期间的版本、解码、缩放和编码。
- 同一来源版本、宽度、高度和质量的冷请求共享一次读取与生成。不同尺寸独立生成；等待者取消不终止已有生成。生成失败传给全部等待者，异常退出也会释放等待者；下一次请求可以重新尝试，本次不会静默重试或改用原图。
- Emby 图片来源解析在作品不存在时先识别媒体库，再查系列。普通作品图片不增加媒体库查找；媒体库图片不再执行系列查找。已读取的库信息传入封面选择，复用既有请求内库快照和最终 PNG 缓存，不新增持久来源、后台预热或扫描。
- 库封面选择、渲染和数据库失败明确返回错误；只有确实没有素材的库返回 404。

原图仍须存在，原图大小/修改时间仍参与失效判定。普通变体保留原有磁盘缓存容量和写入准入策略；缓存繁忙时可以发送已完成的生成结果，不把它报告为已写入缓存。

表中为最大宽度 / JPEG 质量。其他原先高于 85 的展示图片调整到 82；原有小图尺寸和较低质量保留。大图仍按用户点击加载。TMDB 直连使用其受支持的 CDN 尺寸，质量参数不会由服务器再次编码。

第三方 Emby 客户端明确传入的尺寸和质量保持有效，不在服务器静默改写。不同尺寸仍拥有各自的变体缓存。

## 耗时观测

图片响应增加 `Server-Timing`，按实际经过的阶段提供毫秒值：

- `img_lookup`：Emby 图片来源解析。
- `img_selection`：媒体库封面素材选择。
- `img_cover`：最终封面获取，包含缓存查找或冷渲染。
- `img_cache`：普通变体成品文件打开、检查，不包含响应体发送。
- `img_read`、`img_transform`、`img_write`：普通变体生成者的原图加载、解码缩放编码、缓存写入尝试。
- `img_wait`：相同变体等待者的等待时间。

库封面仅冷生成时记录 `library cover generated` 日志，包含素材读取、绘制编码耗时、尺寸和输出字节数；不记录原图 URL、私有路径或库名。

## 本地验证

```powershell
go test ./internal/service ./internal/handler ./internal/repository ./internal/config -count=1
go test ./internal/service -run '^$' -bench '^BenchmarkImageVariantCacheReadOrder$' -benchmem -benchtime=500ms -count=3
cd web
npm run build
```

以上测试及构建通过。覆盖缓存命中不读取来源、来源版本/参数失效、GET/HEAD/304、并发生成、独立取消、失败及 panic 释放等待者，以及自动/手选封面只查一次目标库且不查询系列。测试使用本地数据库、示意图片和模拟网络，没有真实 115 请求。

Windows amd64 / i5-12600KF，使用仓库示意 PNG（417805 字节），两组都先建立同一份热变体缓存：

| 读取顺序 | 三次耗时（ms/op） | 分配（B/op） |
| --- | --- | --- |
| 原图先读完再查变体 | 1.186 / 0.842 / 0.927 | 约 2025815 |
| 原图元数据后直接查变体 | 0.127 / 0.134 / 0.127 | 43727 |

这是单次热缓存处理的局部对照，不包含数据库、客户端网络或 CDN 下载，不能推算为整页或生产延迟降幅。

同一张仓库示意图的离线编码与目视检查：卡片 66157 → 40578 字节（减少 38.7%），详情海报 48451 → 27210（43.8%），模糊背景 79871 → 38771（51.5%），点击大图 106668 → 81889（23.2%）。图中大字、边缘和渐变可辨；该图是示意素材，不能替代真实照片、电视设备和不同网络下的画质及流量验证。临时对照图片和生成脚本已清理。

新增缓存及并发测试连续运行 20 次通过。修改的网页文件通过 ESLint（0 错误，`AdultPerformerModal.tsx` 保留原有的 useEffect 依赖警告，未改动该 Hook）。本机 CGO 关闭且没有 C 编译器，未运行 Go race detector；执行了确定性并发测试。真实客户端和生产运行耗时尚未验证。
